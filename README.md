# Portfólio — Wagner Rodrigo

## Sobre o projeto

Este repositório apresenta meu portfólio pessoal, com informações sobre minha trajetória, habilidades, estudos e projetos desenvolvidos na área de tecnologia.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Estrutura do projeto

- `index.html`: página principal do portfólio.
- `css/style.css`: estilos e layout da página.
- `img/`: imagens e logotipos.
- `projetos/`: páginas complementares e projetos.

## Objetivo

Praticar desenvolvimento web, organização de arquivos e controle de versão com Git e GitHub.

## Publicação

O portfólio será publicado utilizando o GitHub Pages, permitindo
acessar a página diretamente pelo navegador.

## Acesso ao projeto

O código-fonte está disponível neste repositório do GitHub.
As atualizações do projeto são organizadas em branches e integradas
à branch principal por meio de Pull Requests.
